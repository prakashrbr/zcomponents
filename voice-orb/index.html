Voice Orb

An animated orb for recording and transcription. Six looks and six states in one custom element, with no dependencies.

Usage


    
// Drive it from your recorder
const orb = document.querySelector('voice-orb');

orb.state = 'listening';
orb.level = analyserLevel;   // 0 to 1, every frame

orb.state = 'processing';
orb.progress = 0.4;        // optional; leave unset to spin

orb.state = 'done';

State changes are announced politely to screen readers. With reduced motion turned on, the orb holds still and only fades between states. It reads its own text colour to tell light backgrounds from dark ones.
