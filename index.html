zcomponents

Date, time and review components

Components for clinical workflows in plain JavaScript and CSS, with no dependencies or build step. Each demo shows every state and feature in the custom design, Ant Design and MUI, in light and dark mode. Pick one from the side navigation.

For developers: start with the README.md in this repository, then each component folder's own README. Load calendar-date-picker/datepicker.css and datepicker.js first: they're the shared core for every component.
Run the demos locally: serve this folder over HTTP (opening the pages with file:// blocks the scripts), then open http://localhost:5174. 
python -m http.server 5174
